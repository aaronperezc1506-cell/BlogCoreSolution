# SUPORTSAARON
Proyecto académico ASP.NET Core MVC .NET 10 basado en BlogCore, adaptado a una tienda temática de aparatos electrónicos.

- Tema: aparatos electrónicos.
- Marca: Suportsaaron.
- Pie: © Derechos reservados. Desarrollado por Aaron Perez 11 06.
- Persistencia: SQL Server / Entity Framework Core.
- Seguridad: ASP.NET Core Identity y roles Administrador, Registrado y Cliente.
- Contenido inicial: 4 categorías, 24 artículos y 4 sliders activos de demostración.
- Panel administrativo: `/Admin/Categorias`, `/Admin/Articulos`, `/Admin/Sliders`.

Consulta `GUIA_CONEXION_PUBLICACION.md` para abrir, conectar SQL Server Management Studio y publicar en MonsterASP.NET.
